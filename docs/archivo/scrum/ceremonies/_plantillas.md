# Plantillas de ceremonias

Copiar cada bloque a un archivo `sprint-N-<ceremonia>.md` y rellenar el mismo día.
La evidencia vale por ser **real y fechada**, no por ser extensa.

---

## Sprint Planning

```
# Sprint N — Planning
Fecha: AAAA-MM-DD
Duración del sprint: 2 días (AAAA-MM-DD → AAAA-MM-DD)

## Objetivo del Sprint
<una frase>

## Historias comprometidas
| HU | Título | Pts | Criterio de "hecho" para este sprint |
|----|--------|----:|--------------------------------------|

## Capacidad y supuestos
- Horas disponibles reales:
- Riesgos conocidos al empezar:

## Desglose técnico (Sprint Backlog)
- HU-XX
  - [ ] tarea 1
  - [ ] tarea 2
```

---

## Daily (registro breve, 1 por día)

```
# Sprint N — Daily AAAA-MM-DD
- Hecho ayer:
- Plan de hoy:
- Impedimentos:
- Puntos restantes (para el burndown):
```

## Sprint Review

```
# Sprint N — Review
Fecha: AAAA-MM-DD
Asistentes: (tesista; tutor si participó)

## Incremento demostrado
<qué se mostró funcionando>

## Verificación de criterios de aceptación
| HU | Criterio | Resultado (OK / parcial / no) | Nota |
|----|----------|-------------------------------|------|

## Historias aceptadas / no aceptadas
- Aceptadas:
- No aceptadas y por qué:

## Puntos completados: X / Y comprometidos
```
