# Burndown por sprint

Registrar los **puntos de historia restantes** al cierre de cada día. Al terminar el
sprint, graficar (línea real vs. línea ideal) en Excel/Sheets y exportar la imagen a
esta carpeta como `sprint-N-burndown.png`.

## Cómo se calcula

- **Restante** = suma de puntos de las historias del Sprint Backlog que **todavía no** cumplen la Definition of Done.
- Una historia aporta sus puntos completos hasta que está 100% `Hecha` (no se cuentan medios avances).
- **Línea ideal** = recta desde (día 0, total comprometido) hasta (último día, 0).
